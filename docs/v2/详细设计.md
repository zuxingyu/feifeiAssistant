## 2. 状态机设计

### 2.1 状态定义

```cpp
enum DeviceState {
    STATE_SETUP_BOOT,    // 首次开机配网引导（设备屏）
    STATE_SETUP_WIFI,    // 网页 Step1：WiFi 配置
    STATE_SETUP_SCHED,   // 网页 Step2：课程表配置
    STATE_SETUP_WEATHER, // 网页 Step3：天气配置
    STATE_SETUP_DONE,    // 网页 Step4：完成
    STATE_HOME,          // 主页（常显对话条）
    STATE_MUSIC,         // 音乐播放器
    STATE_SCHEDULE,      // 课程表
    STATE_WEATHER,       // 天气详情
    STATE_SLEEP,         // 休眠（灭屏）
};
```

### 2.2 事件定义

```cpp
enum DeviceEvent {
    EVT_SETUP_COMPLETE,   // 配网四步全部完成
    EVT_KEY_A_PRESS,      // 按键 A（下一页）
    EVT_KEY_B_PRESS,      // 按键 B（唤醒 / 确认）
    EVT_KEY_C_PRESS,      // 按键 C（返回主页）
    EVT_WAKE_TRIGGER,     // 唤醒触发（语音或按键 B）
    EVT_TICK_MINUTE,      // 每分钟定时器
    EVT_WIFI_CONNECTED,   // WiFi 连接成功
    EVT_WEATHER_UPDATED,  // 天气数据更新
};
```

### 2.3 状态转换表

| 当前状态 | 事件 | 下一状态 | 动作 |
|---------|------|---------|------|
| SETUP_BOOT | 配网完成 | SETUP_WIFI→DONE→HOME | 启动 HTTP Server |
| SETUP_WIFI | 提交WiFi | SETUP_SCHED | 保存 SSID/Pass |
| SETUP_SCHED | 提交课程表 | SETUP_WEATHER | 保存课程数据 |
| SETUP_WEATHER | 提交天气 | SETUP_DONE | 保存 Key/Secret |
| SETUP_DONE | 连接成功 | HOME | 切换到主页 |
| HOME | EVT_KEY_A | MUSIC | 切换页面 |
| HOME | EVT_TICK_MINUTE | HOME | 刷新时间/天气 |
| MUSIC | EVT_KEY_A | SCHEDULE | 切换页面 |
| MUSIC | EVT_KEY_B | MUSIC( wake) | 弹出对话框 |
| SCHEDULE | EVT_KEY_A | WEATHER | 切换页面 |
| SCHEDULE | EVT_KEY_B | SCHEDULE(wake) | 弹出对话框 |
| WEATHER | EVT_KEY_A | HOME | 切换页面 |
| WEATHER | EVT_KEY_B | WEATHER(wake) | 弹出对话框 |
| ANY(C不回到HOME) | EVT_KEY_C | HOME | 返回主页 |
| ANY | EVT_WAKE_TRIGGER | 同页(wake) | 弹对话框3秒 |

## 3. 模块详细设计

### 3.1 WiFi 配网模块（wifi_config）

**职责**：
- 首次上电时作为 SoftAP 热点运行（SSID: `XZ-Setup-XXXX`）
- 内置 HTTP Server，路由 `/`, `/wifi`, `/schedule`, `/weather`, `/done`
- 所有配网页面以 C 字符串形式内置，不依赖文件系统

**关键 API**：

```cpp
// wifi_config.h
void wifi_config_start_softap();      // 启动 SoftAP
void wifi_config_stop_softap();       // 配网完成后关闭 SoftAP
void wifi_config_start_http_server(); // 启动 HTTP Server
bool is_wifi_configured();            // 检查是否已完成配网
```

**HTTP 路由**：

| 路由 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 返回 setup-start 页面（设备首屏 SSID+IP 引导）|
| `/wifi` | GET/POST | WiFi 配置页面 / 接收 SSID + 密码 |
| `/schedule` | GET/POST | 课程表配置页面 / 接收课程数据 |
| `/weather` | GET/POST | 天气配置页面 / 接收 Key/Secret |
| `/done` | GET | 完成页面，显示绑定号码 |
| `/api/save` | POST | 统一保存配置到 NVS |

**配置保存后行为**：
1. 保存数据到 NVS
2. 重启 WiFi 为 Station 模式连接家庭网络
3. 连接成功后发布 MQTT 绑定请求
4. 切换到 `STATE_HOME`

### 3.3 课程表模块（schedule）

**核心计算逻辑**：

```cpp
// schedule.h
typedef struct {
    const char* name;   // 课程名
    int         room;   // 教室号（可选）
} Lesson;

typedef struct {
    Lesson morning[4];    // 上午4节
    Lesson afternoon[4];  // 下午4节
} DaySchedule;

typedef struct {
    DaySchedule single_week[5];  // 周一～周五
    DaySchedule double_week[5];
} TermSchedule;

// 判断当前是单周还是双周
WeekType get_current_week_type(const char* start_date);

// 获取今日/明日课程
DaySchedule get_today_schedule(const TermSchedule* term);
DaySchedule get_tomorrow_schedule(const TermSchedule* term);
```

**单双周判断算法**：
```
1. 读取配置的学期开始日期 start_date
2. 计算从 start_date 到今天(TODAY)的天数差 N
3. N / 7 % 2 == 0 → 单周，否则 → 双周
4. （开学第一周为单周）
```

### 3.4 天气模块（weather）

**API**：心和天气（[seniverse.com](https://www.seniverse.com)）

**请求格式**：
```
GET https://api.seniverse.com/v3/weather/daily.json
  ?key=<WEATHER_KEY>
  &location=<CITY>
  &language=zh-Hans
  &unit=c
```

**响应解析**：
```json
{
  "results": [{
    "location": { "name": "深圳" },
    "daily": [
      { "date": "2025-01-04", "text_day": "晴", "high": "22", "low": "14" },
      { "date": "2025-01-05", "text_day": "多云", "high": "21", "low": "13" },
      { "date": "2025-01-06", "text_day": "小雨", "high": "19", "low": "12" },
      { "date": "2025-01-07", "text_day": "阴", "high": "18", "low": "11" }
    ]
  }]
}
```

**数据刷新**：每 30 分钟请求一次，请求失败时保留上次数据。

**缓存结构**：
```cpp
typedef struct {
    char  date[11];       // "2025-01-04"
    char  text[8];        // "晴"
    int   high;           // 22
    int   low;            // 14
} DailyWeather;

typedef struct {
    DailyWeather forecast[4];  // 今天起4天
    int          humidity;      // 湿度
    int          wind_level;    // 风力等级
    char         pm25[4];       // "良" / "优" 等
    time_t       last_update;   // 上次更新时间
} WeatherData;
```

### 3.6 按键处理

硬件按键映射（A/B/C 三个，无触摸）：

| 按键 | GPIO | 功能 |
|------|------|------|
| A | GPIO0 | 翻到下一页 |
| B | GPIO47 | 唤醒（弹出对话框） |
| C | GPIO48 | 返回主页 |

**按键消抖**：10ms 软消抖

**长按**：
- 按住 B 3秒：强制重启配网（恢复出厂设置）

**GPIO 初始化**（在 `waveshare-s3-rlcd-4.2.cc` 中）：
```cpp
gpio_config_t conf = {
    .pin_bit_mask = (1ULL << GPIO0) | (1ULL << GPIO47) | (1ULL << GPIO48),
    .mode = GPIO_MODE_INPUT,
    .pull_up_en = GPIO_PULLUP_ENABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_ANYEDGE,
};
gpio_config(&conf);
gpio_isr_handler_add(GPIO0, gpio_isr_handler, NULL);
gpio_isr_handler_add(GPIO47, gpio_isr_handler, NULL);
gpio_isr_handler_add(GPIO48, gpio_isr_handler, NULL);
```

### 3.7 定时刷新策略

```cpp
// 在 app.cc 主循环中
static time_t last_minute_tick = 0;

void app_main_loop() {
    time_t now = time(NULL);
    if (now - last_minute_tick >= 60) {
        last_minute_tick = now;
        // 触发 STATE_TICK_MINUTE 事件
        state_machine_dispatch(EVT_TICK_MINUTE);
        // 强制 LVGL 全量刷新
        lv_obj_invalidate(lv_scr_act());
    }
}
```

**IDF 版本**：ESP-IDF 5.x

**Kconfig.projbuild 关键配置**：
```
CONFIG_ESPTOOLPY_FLASHFREQ_120M=y
CONFIG_ESPTOOLPY_FLASH_SIZE=8MB
CONFIG_LVGL_MEM_BYTES=32768
CONFIG_FREERTOS_HZ=1000
CONFIG_ESP_WIFI_SSID="XZ-Device"
```
