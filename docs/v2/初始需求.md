背景：

1. 这个项目是从<https://github.com/78/xiaozhi-esp32上fork的。>
2. 当前屏幕不支持触屏，分辨率是400 \* 300 ，不支持彩色，只有单色黑色，有三个物理按钮，我暂且命名为A，B，C,三个均为实体按钮，且
3. 当前开发板为waveshare的esp32-s3-rlcd-4.2型号，在开发前请查找这个微雪型号的资料，了解这个板子的基本功能
4. 这个开发板项目面向的对象是小学生，要求简单字体清晰。
5. 可以参考[https://github.com/ZhouhaoJiang/xiaozhi-esp32 的代码，进行二次开发。](https://github.com/ZhouhaoJiang/xiaozhi-esp32的代码，进行二次开发。)

需求：

1. 所有的UI图形都用HTML画，
2. 保持开发板中图标的统一。
3. 所有页面的右上角为WiFi的信号强度图标和电池的电量图标和百分比，WiFi图标和电池图标不要做成表情包。
4. 每个页面均要有小智的语音对话框用于显示对话问题，可统一也可以根据页面的排版进行页面的独立适配，
5. 主要流程：
   1. 第一次加载时，页面显示当前ESP32S3的WiFi名称和IP地址，提示连接
   2. 使用电脑和手机查找附近的ESP32S3面板的WiFi信号并连接，在电脑或手机的浏览器中打开屏幕中显示的IP地址
   3. 网页显示欢迎页面。
      1. 第一步显示附近的WiFi SSID列表，选择一个可连接的WiFi，下面文本框输入其密码，
      2. 点击下一步，进入第二页，显示课程表编写页面，显示学期开始日期和学期结束日期，可以使用滑动的日期控件填写。课程表分为单双周，部分课程表内容可以从单周复制到双周中，上午设置3-4节课，下午设置3-4节课，文本框输入。设置学期开始时间的那一周为第一周（单周）后面以此类推
      3. 点击下一步，进入第三页，第三页显示配置天气信息的Key和Secret，使用心和天气连接
      4. 点击完成，实现网页配置流程结束
      5. 网页配置流程结束后，进入主页，开发板读取WiFi信息，实现联网至小智地址，主页中部内容替换为小智的号码，在小智网站的控制台上输入号码即可完成小智的绑定，真正进入主页。
6. 面板共有四个页面，如下说明：
   1. 主页：主页应该包含时间，日期，近三日当地天气，今日课程和明日课程以及小智的聊天对话框，没有聊天时显示“待命”字样，如果明日为周末，课程为空，或者显示一个开心的表情。
   2. 音乐播放器：点击A按钮显示第二页。第二页展示音乐和故事播放页面。显示歌词、歌手、专辑，以及当前播放时间和总时间。
   3. 课程表：再点击A按钮显示第三页。第三页展示本周课程表，显示本周（单双周）日期（x月x日-x月x+7日），上午、下午课程。上午课程为四个，下午课程为四个，中间空隙多一些。
   4. 再点击A按钮显示第四页。第四页展示天气详情，近四天的天气走势，天气情况，气温趋势为最高温和最低温两个趋势，近四天的最高温连接，近四天的最低温连接形成折线，
   5. 所有页面出主页外，左上角显示：时间  温度   湿度  如下：1月2日 12:33  22℃   65%；右上角显示WiFi信号强度和电池电量，如果是充电的，显示充电状态，只有主页显示和小智的对话聊天文字内容，其他页面只有在唤醒时候才会出现，待命时消失
7. 每分钟刷新一次减少功耗
