# 原型说明

## 1. 概述

本目录包含小智 AI 智能助手 ESP32-S3-RLCD-4.2 设备的完整交互原型，以 HTML 文件形式呈现，可直接在浏览器中打开体验。

**硬件分辨率**：400 × 300 像素，单色黑色。

---

## 2. 文件清单

### 2.1 设备屏幕页面（`device-*.html`）

| 文件 | 说明 | 对话框规则 |
|------|------|-----------|
| `setup-start.html` | 首次开机配网引导 | 无（设备屏） |

| `device-schedule.html` | 课程表 | 唤醒时弹出，3秒后消失 |
| `device-weather.html` | 天气详情 | 唤醒时弹出，3秒后消失 |

| 文件 | 说明 |
|------|------|

| `setup-weather.html` | Step 3 — 填写心和天气 Key / Secret |

| 文件 | 说明 |

## 4. 对话框规则详解

### 4.1 常驻对话（仅主页）
- 位置：屏幕最底部，高度 24px
- 内容：设备启动后固定显示`小智: 待命`
- 语音对话触发时，内容更新为对话内容

### 4.2 唤醒弹出（音乐/课程表/天气页）
- 触发条件：按物理按键 B，或语音唤醒词"小智"检测成功
- 位置：屏幕最底部，覆盖条
- 样式：顶部 2px 黑色分割线，与常驻对话条外观一致
- 持续时间：弹出后 3 秒自动隐藏
- 动画：淡入淡出（CSS opacity 0→1→0），可选

### 4.3 配网页面的对话框
- 配网页面为纯 HTML 网页，不在设备屏幕上显示
- 不涉及设备对话框规则

## 5. 状态栏规则

所有设备页面顶部均包含 28px 高度状态栏，内容一致：

| 位置 | 内容 |
|------|------|
| 左侧 | 日期（`1月2日`）+ 时间（`12:33`）+ 温度（`22°C`）+ 湿度（`65%`） |
| 右侧 | WiFi 信号强度图标（4格）+ 电池图标 + 百分比（`82%`） |

---

## 6. 配网页面规则

### 6.1 设备首屏（setup-start.html）
- 唯一在设备屏幕上显示的配网引导
- 内容：WiFi 热点 SSID（`XZ-Setup-XXXX`）+ 芯片映射 IP（`192.168.4.1`）
- 用户必须连上该热点后，在浏览器输入 IP 地址

### 6.2 网页四步（setup-*.html）
- 全部通过手机/电脑浏览器访问，不在设备屏幕上显示
- Step1 WiFi：显示可用 SSID 列表（模拟数据），用户选择后输入密码
- Step2 课程表：设置学期起止日期，自动判断单双周；可分别填写单周和双周课程
- Step3 天气：填写心和天气 Key 和 Secret（必填），城市（可选）
- Step4 完成：显示绑定号码（`XZ-XXXX`），提示用户到小智控制台完成绑定

### 6.3 配置数据流
```
用户填写网页表单
    ↓ POST /api/save
ESP32 HTTP Server 接收数据
    ↓ 保存到 NVS
设备重启并连接家庭 WiFi
    ↓ MQTT 绑定请求
小智云服务器 → 设备主页中部显示绑定号码
```

## 7. 刷新策略

| 触发条件 | 刷新内容 |
|---------|---------|
| 每 60 秒 | 全屏 LVGL 重绘（强制刷新） |
| 每 30 分钟 | 天气数据从心和天气 API 重新获取 |
| 按键 A 按下 | 切换到对应页面（立即刷新） |
| 按键 B 按下 | 弹出唤醒对话框（3秒后隐藏） |

---

## 8. 原型使用建议

1. **设备页面**：用浏览器打开对应 HTML 文件，将浏览器窗口大小调整为 400×300 像素，即可 1:1 模拟设备屏幕显示效果
2. **配网页面**：在浏览器中全屏打开，可完整体验用户配置流程
3. **页面切换**：在原型中通过刷新页面模拟物理按键 A 的翻页效果
4. **唤醒效果**：音乐/课程表/天气页面中，按下右下角"唤醒小智"按钮可预览唤醒弹出效果
