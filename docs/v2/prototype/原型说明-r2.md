# 原型说明 R2

## 1. 文档定位

本文档用于说明 `docs/v2/prototype/ui-r2/` 目录中的第二版原型。

R2 原型采用方案 B：

- 保留 `docs/v2/prototype/ui/` 旧版原型不动
- 在 `docs/v2/prototype/ui-r2/` 中单独维护二开确认版原型

这样做的目的是：

- 保留旧版原型供回看
- 避免旧版页面被覆盖后无法追溯
- 让二开确认版原型可以逐页迭代

## 3. R2 已确认规则

### 3.1 首次配网页

`setup-start.html` 当前已按以下规则修订：

- 页面标题使用“首次配网”
- 顶部状态栏不显示 WiFi
- 顶部只保留温湿度和电池/充电信息
- 主体区域显示：
  - `WiFi名称`
  - `访问地址`
- 标签和值上下排布
- 页面文案为中文
- 底部提示为“等待连接中...”

### 3.2 原型与实现关系

R2 原型的作用是先确认页面视觉和信息结构，再指导板级代码实现。

实现顺序建议为：

1. 先确认 HTML 原型
2. 再按原型调整 `LVGL`
3. 最后联调板级逻辑和页面切换

### 3.3 激活小智页面

`device-activation.html` 当前用于承载设备联网后的“输入小智号码”页面，规则如下：

- 这是一个设备屏幕页面，不是浏览器页面
- 页面中部突出显示“小智号码”
- 页面提示用户到小智控制台输入号码
- 绑定完成后自动进入主页
- 顶部状态栏恢复显示 WiFi 与电池信息

## 6. 后续使用建议

在进入下一步 `LVGL` 开发前，建议先完成以下确认：

1. 确认 `setup-start` 的标题、图标、状态栏和正文布局
2. 确认 `device-activation` 的“小智号码”展示方式和文案
3. 确认 `setup-done` 与 `device-activation` 的衔接关系
4. 确认 `device-home` 的信息层级和底部对话条样式
5. 再开始把这些页面一一映射到板级显示实现
