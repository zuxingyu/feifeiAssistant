## 1. 设计目标

本次 UI 设计面向 `waveshare-esp32-s3-rlcd-4.2` 的 400x300 黑白 RLCD 屏幕，目标是让页面在真实设备上具备以下特性：

- 远距离可读
- 中文信息不截断
- 页面结构稳定
- 状态栏始终清晰
- 符合儿童用户的理解习惯

---

## 2. 设计原则

### 2.1 可读优先

- 字体清晰优先于装饰效果
- 中文标题和标签优先保证完整显示
- 不在同一行堆叠过多字段

### 2.2 黑白优先

- 所有图标按黑白单色设计
- 重要信息依靠版式、粗细、留白区分
- 不依赖颜色表达状态

### 2.3 信息层级稳定

- 顶部为状态栏
- 中部为页面主体
- 底部为对话条或提示条
- 页面切换时尽量保持这三段结构不变

### 2.4 适应 RLCD 刷新特性

- 频繁变化内容尽量集中在局部区域
- 减少大面积无意义重绘
- 尽量避免复杂大图和高频闪烁效果

### 2.5 设计落地原则

- 本稿描述的是页面视觉和交互规则，不预设必须新建新的公共目录体系
- 与本板强相关的页面布局和切换逻辑，优先在 `main/boards/waveshare/esp32-s3-rlcd-4.2/` 下实现
- 公共显示层只负责提供必要的基础能力，例如状态栏、主题和通用显示接口
- 当某个 UI 能力已经明确可跨板复用时，再考虑向公共层抽离

## 3. 设备屏视觉规范

### 3.1 屏幕基础规格

- 分辨率：`400 x 300`
- 显示方向：横屏
- 显示颜色：黑白
- 触控能力：无

### 3.2 页面基础分区

建议所有设备页采用统一三段式结构：

#### 3.2.1 顶部状态栏

- 高度建议：`28px ~ 32px`
- 用途：时间、温湿度、电池、充电状态；除 `setup-start` 外的其他设备页可显示 WiFi

#### 3.2.2 主体内容区

- 高度建议：`236px ~ 244px`
- 用途：页面核心信息

#### 3.2.3 底部条

- 高度建议：`24px ~ 32px`
- 用途：
  - 首页常驻对话条
  - 子页面临时对话层
  - 配网首屏底部等待提示

---

## 4. 字体规范

### 4.1 总体建议

当前板级默认大字号不适合这套页面，二开版建议采用更紧凑的字号体系。

建议在设备端为页面单独定义一组适合 RLCD 的字体规格。

### 4.2 建议字号体系

| 用途 | 建议字号 | 说明 |
|------|---------|------|
| 页面主标题 | 22px | 如“首次配网”“设备激活中” |
| 大时钟 | 28px | 首页时间 |
| 二级标题 | 18px | 如“今日课程”“近四天天气” |
| 正文主信息 | 14px | 课程、天气、状态说明 |
| 标签/说明 | 12px | 如“WiFi名称”“访问地址” |
| 辅助文字 | 10px | 页脚、更新时间等 |

### 4.3 字体使用规则

- 标题最多 1 行
- 标签和对应值尽量上下排布
- 滚动文本只用于 SSID、URL 等极端长字段
- 不让多个中文标签和动态值硬挤在同一行

---

## 5. 图标规范

### 5.1 风格要求

- 统一使用简洁线性图标或实体单色图标
- 不使用表情包样式的 WiFi / 电池图标
- 避免过于细碎的纹理

### 5.2 状态栏图标

必须统一风格的图标：

- WiFi 强度
- 电池
- 充电
- 静音或音量状态

### 5.3 页面功能图标

允许页面中使用功能图标，但必须满足：

- 与状态栏图标风格一致
- 在黑白显示下仍可识别
- 不压缩正文信息空间

---

## 6. 通用组件设计

### 6.1 状态栏

#### 6.1.1 左侧信息

首页建议：

- 日期
- 时间

子页面建议：

- 时间
- 温度
- 湿度

说明：

- 如果空间允许，可统一成“日期 + 时间 + 温度 + 湿度”
- 但优先保证可读性，不强行塞满

#### 6.1.2 右侧信息

必须保留：

- WiFi 图标
- 电池图标
- 电量百分比

可选保留：

- 充电状态

#### 6.1.3 样式规则

- 状态栏底部加 1px 分隔线
- 文本纵向居中
- 左右留边建议 `8px ~ 12px`

### 6.2 页面标题

- 页面标题与主体内容之间保留 `8px ~ 12px` 间距
- 标题居左或居中二选一，不混用
- 建议：
  - 配网页、激活页居中
  - 功能页居左

### 6.3 内容卡片

适用于：

- WiFi 信息
- 访问地址
- 绑定码
- 天气摘要

建议卡片样式：

- 1px 或 2px 黑色边框
- 内边距 `8px ~ 12px`
- 上下分组，减少横向拥挤

### 6.4 对话条

首页：

- 常驻显示
- 高度建议 `24px`
- 文案单行截断或滚动

子页面：

- 默认隐藏
- 唤醒时弹出
- 样式与首页保持统一

## 7. 页面设计

### 7.1 设备配网首屏

#### 7.1.1 版式目标

- 高信息密度但不拥挤
- 顶部状态栏保留
- SSID 和 URL 必须完整显示

#### 7.1.2 建议布局

- 状态栏：`30px`
- 标题区：`40px`
- SSID 区：`54px`
- URL 区：`54px`
- 提示区：`60px`
- 底部等待条：`24px`

#### 7.1.3 关键细节

- “WiFi名称”和实际 SSID 分两行
- “访问地址”和实际 URL 分两行
- 长字符串采用水平滚动或裁切加省略策略
- 主提示文字不超过 2 行
- 页面实现优先落在本板显示类中，不单独为了该页建立新的公共 UI 目录

### 7.2 激活页

#### 7.2.1 版式目标

- 突出绑定码
- 让家长能快速理解下一步操作

#### 7.2.2 建议布局

- 页面标题居中
- 绑定码区域占中部主要视觉焦点
- 底部保留“等待绑定”或状态提示

#### 7.2.3 关键细节

- 绑定码字号必须大于普通正文
- 建议为绑定码增加边框框选
- 支持“绑定成功”后直接替换成成功提示

### 7.3 首页

#### 7.3.1 信息优先级

首页推荐优先级如下：

1. 时间
2. 近三日天气
3. 今日课程
4. 明日课程
5. 小智对话条

#### 7.3.2 建议布局

- 顶部状态栏：`28px`
- 时间区：`52px`
- 三日天气区：`44px`
- 今日课程区：`58px`
- 明日课程区：`58px`
- 对话条：`24px`

#### 7.3.3 关键细节

- 时间区采用较大字体
- 三日天气尽量用文字 + 小图标，而不是复杂图表
- 今日/明日课程使用分块标题
- 文本过长时优先压缩课程数量展示方式，不挤压状态栏和对话条
- 首页与子页面切换优先在本板显示实现中管理，避免为了当前板型过早引入新的公共页面框架

### 7.4 音乐页

#### 7.4.1 信息优先级

1. 歌曲名
2. 进度
3. 歌词
4. 歌手/专辑

#### 7.4.2 建议布局

- 顶部状态栏
- 页面标题或歌曲名
- 歌手/专辑副标题
- 进度条
- 歌词区
- 底部弹出对话层预留区

#### 7.4.3 关键细节

- 歌曲名一行显示
- 歌手/专辑缩小字号
- 歌词区最多显示 3 行主歌词

### 7.5 课程表页

#### 7.5.1 信息优先级

1. 单双周和周范围
2. 课程表网格

#### 7.5.2 建议布局

- 顶部状态栏
- 单双周标签 + 日期范围
- 课程表网格主体
- 底部弹出对话层预留区

#### 7.5.3 关键细节

- 课程格子优先保证列宽均匀
- 上午与下午之间留更大空隙
- 课程名建议限制为 2 至 4 个字

### 7.6 天气页

#### 7.6.1 信息优先级

1. 四日天气摘要
2. 高低温趋势
3. 湿度 / 风力 / 空气质量

#### 7.6.2 建议布局

- 顶部状态栏
- 页面标题
- 四日天气摘要区
- 趋势图区
- 底部信息条
- 对话层预留区

#### 7.6.3 关键细节

- 趋势图线条粗细不同以区分高温线和低温线
- 每个日期节点都要有可读文本
- 湿度和风力采用横向简表，不做复杂组件

## 8. 对话层设计

### 8.1 首页常驻对话条

- 位置：底部
- 高度：`24px`
- 样式：1px 顶部分隔线 + 左对齐文案
- 默认文案：`小智：待命`

### 8.2 子页面弹出对话层

- 位置：底部覆盖
- 高度：`24px ~ 32px`
- 触发：按键 `B` 或语音唤醒
- 自动隐藏：建议 3 秒

### 8.3 文案规则

- 优先显示中文短句
- 单行显示不下时允许跑马灯或省略
- 不影响主体内容阅读

## 9. 刷新与重绘建议

### 9.1 高优先内容

适合局部刷新：

- 状态栏时间
- WiFi 状态
- 电池电量
- 对话条内容

### 9.2 中低频内容

适合定时刷新：

- 温湿度
- 天气摘要
- 课程表日期范围

### 9.3 页面切换

- 页面切换允许整体重绘
- 页面内局部变化尽量局部刷新

## 10. 风险与规避

### 10.1 字体过大风险

风险：

- 状态栏被挤压
- `WiFi名称`、`访问地址` 被截断

规避：

- 使用页面专用较小字体
- 标签和值上下排版

### 10.2 顶部栏被覆盖风险

风险：

- 配网页或激活页覆盖状态栏

规避：

- 页面主体从状态栏下方开始布局
- 不隐藏顶部栏对象

### 10.3 黑白图标识别风险

风险：

- 图标过于复杂后识别度下降

规避：

- 只保留必要图标
- 使用简化线稿或单色块面图形
