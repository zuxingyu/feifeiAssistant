## 0. 文档边界

本文只负责回答：

1. 页面有哪些
2. 页面之间如何流转
3. 设备页和浏览器页如何衔接

本文不负责：

1. 定义最终视觉风格和字号体系
2. 定义代码模块拆分和文件落点
3. 定义开发顺序和准入关口

阅读建议：

- 配合 `06-整体设计与原型落地方案.md` 确认原型验收顺序

## 1. 文档定位

本文档用于定义二开版本的原型结构与页面流转规则。

本稿不直接替换旧版 `docs/v2/prototype/ui` 下的 HTML，而是作为第二版原型重绘和设备页面开发的依据。

本稿对应的实现原则为：

- 原型继续从页面和流程角度描述产品
- 代码实现优先落在 `main/boards/waveshare/esp32-s3-rlcd-4.2/` 板级目录
- 公共显示层和公共联网层仅做最小必要扩展

---

## 2. 原型拆分原则

本次原型分为两类：

### 2.1 设备端原型

设备端原型对应真实设备屏幕，遵守以下条件：

- 分辨率固定为 `400 x 300`
- 黑白单色
- 无触摸
- 设备端页面最终用 `LVGL` 实现

### 2.2 浏览器端原型

浏览器端原型用于首次配置流程，遵守以下条件：

- 在手机和电脑浏览器中打开
- 页面以 `HTML` 实现
- 重点是表单流程清晰、输入步骤简单

## 4. 全流程流转

### 4.1 首次开机主流程

```text
开机
  ↓
检测历史 WiFi
  ↓
若无历史 WiFi
  ↓
设备显示 setup-start
  ↓
用户连接设备热点
  ↓
浏览器打开 192.168.4.1
  ↓
setup-wifi
  ↓
setup-schedule
  ↓
setup-weather
  ↓
setup-done
  ↓
设备连接家庭 WiFi
  ↓
activation
  ↓
绑定成功
  ↓
device-home
```

### 4.2 日常使用流程

```text
device-home
  ↓ A
device-music
  ↓ A
device-schedule
  ↓ A
device-weather
  ↓ A
device-home

任意子页面
  ↓ C
device-home

任意子页面
  ↓ B 或语音唤醒
底部弹出小智对话层
```

## 5. 设备端页面原型

### 5.1 `setup-start` 设备配网首屏

#### 5.1.1 页面目标

- 让用户一眼知道设备正在等待配网
- 明确展示热点名和访问地址
- 保留顶部状态栏，避免用户误以为设备死机

#### 5.1.2 页面结构

```text
┌────────────────────────────────────┐
│ 日期/时间/温湿度        电池/充电  │
├────────────────────────────────────┤
│                                    │
│              配网图标              │
│            首次配网                │
│                                    │
│  WiFi名称                          │
│  XZ-Setup-XXXX                     │
│                                    │
│  访问地址                          │
│  192.168.4.1                       │
│                                    │
│  请先连接上方热点，再在浏览器中     │
│  打开访问地址完成配置              │
│                                    │
├────────────────────────────────────┤
│            等待连接中...           │
└────────────────────────────────────┘
```

#### 5.1.3 关键要求

- `WiFi名称` 和 `访问地址` 必须分两行展示，避免大字号截断
- 顶部状态栏必须可见
- 页面允许中部图标，但不能压缩到正文可读性

### 5.2 `activation` 激活页

#### 5.2.1 页面目标

- 在联网成功后，引导用户完成设备绑定
- 明确展示当前绑定码或小智号码

#### 5.2.2 页面结构

```text
┌────────────────────────────────────┐
│ 日期/时间/温湿度      WiFi/电池    │
├────────────────────────────────────┤
│                                    │
│            设备激活中              │
│                                    │
│         请在小智控制台输入         │
│             以下号码               │
│                                    │
│            XZ-2038                 │
│                                    │
│      绑定完成后将自动进入主页      │
│                                    │
├────────────────────────────────────┤
│ 小智: 正在等待绑定                 │
└────────────────────────────────────┘
```

#### 5.2.3 关键要求

- 绑定码区域必须显眼
- 页面应有“等待中 / 成功 / 失败可重试”的状态变化空间

## 6. 浏览器端原型

### 6.1 `setup-wifi`

页面信息：

- 顶部标题
- 步骤条
- WiFi 列表
- 密码输入框
- 下一步按钮

交互重点：

- 可手动重扫
- 可显示连接失败提示

### 6.2 `setup-schedule`

页面信息：

- 学期开始日期
- 学期结束日期
- 单周 / 双周切换
- 上午 4 节 / 下午 4 节课程录入
- 复制单周到双周按钮

交互重点：

- 表单足够清晰
- 支持滚动和移动端输入

### 6.3 `setup-weather`

页面信息：

- 天气服务说明
- Key / Secret 输入框
- 城市输入框
- 上一步 / 完成按钮

### 6.4 `setup-done`

页面信息：

- 配置完成提示
- 设备联网说明
- 绑定码展示区域
- 返回提示或自动跳转说明

## 7. 对话层规则

### 7.1 首页

- 常驻显示底部对话条
- 默认文案为“待命”

### 7.2 子页面

- 不常驻显示
- 在按键 `B` 或语音唤醒时弹出
- 建议 3 秒后自动消失

### 7.3 配网相关页面

- 设备配网首屏不需要小智对话条
- 浏览器端配网页面不需要设备对话条

---

## 8. 状态栏规则

### 8.1 首页状态栏

建议展示：

- 日期
- 时间
- WiFi
- 电池

### 8.2 子页面状态栏

建议展示：

- 时间
- 温度
- 湿度
- WiFi
- 电池

### 8.3 配网首屏状态栏

建议保留：

- 温度
- 湿度
- 电池
- 充电状态

说明：

- 首次配网页顶部不显示 WiFi，避免和主体中的热点名称重复
- 配网首屏之前曾出现顶部信息被遮挡的问题
- 第二版原型明确要求顶部区域必须保留，不允许被主体文案挤掉

## 9. 原型与实现映射建议

### 9.1 设备端实现

- `setup-start`
  - 优先由 `custom_lcd_display.cc` 承载页面布局，必要时再最小化扩展 `Display / LcdDisplay`
- `activation`
  - 建议由 `application.cc + custom_lcd_display.cc` 联动展示
- `device-home / music / schedule / weather`
  - 建议优先在本板显示实现中维护页面状态和切换，不先抽新的公共页面管理目录

### 9.2 浏览器端实现

- `setup-wifi / schedule / weather / done`
  - 建议由设备内置 HTTP Server 提供，优先沿着现有配网链路做最小扩展
- 页面模板可继续使用 `HTML` 原型并裁剪成嵌入式版本
