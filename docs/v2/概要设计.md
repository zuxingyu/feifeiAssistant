# 概要设计

## 1. 项目概述

### 1.1 项目名称
小智AI智能助手 — ESP32-S3-RLCD-4.2 儿童桌面终端

### 1.2 项目背景
基于 [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) 二次开发，目标硬件为微雪 ESP32-S3-RLCD-4.2（400×300 单色墨水屏/反射屏，无触摸，三个物理按键 A/B/C）。面向用户为小学生，提供课程表、天气、音乐播放和小智 AI 对话功能。

### 1.3 主要功能

| 功能 | 说明 |
|------|------|
| 配网引导 | 设备首次启动显示热点 SSID + IP，引导用户在浏览器完成全部配置 |
| 网页配置 | 通过芯片映射 IP 在浏览器完成 WiFi、课程表、天气 API 的四步配置 |
| 主页 | 时间、三日天气、今日/明日课程、常显小智对话条 |
| 音乐播放器 | 歌词、歌手、专辑、进度条、播放控制；唤醒时弹出对话框 |
| 课程表 | 单双周切换，学期首周自动判断为单周；唤醒时弹出对话框 |
| 天气详情 | 近四天天气格子 + 高低温双折线趋势图；唤醒时弹出对话框 |
| 小智对话 | 首页常显对话条；其他页面由唤醒触发弹出；待命时显示"待命" |
| 状态栏 | 右上角 WiFi 信号强度 + 电池百分比；充电状态指示 |

### 1.4 技术约束

- **分辨率**：400×300 像素
- **色彩**：单色黑色（仅黑白，无灰度）
- **屏幕类型**：反射型 LCD（RLCD），无背光依赖
- **物理按键**：三个（A/B/C），不显示在 UI 上
- **刷新策略**：每分钟刷新一次以降低功耗
- **开发板**：[ESP32-S3-RLCD-4.2](https://www.waveshare.net/shop/ESP32-S3-RLCD-4.2.htm)

## 3. 模块划分

| 模块 | 职责 | 关键文件 |
|------|------|----------|
| **WiFi 配网模块** | SoftAP + HTTP Server，提供配网页面 | `wifi_config.cc/h` |
| **网页配置模块** | 四步配置页面路由与数据持久化 | `web_config.cc/h` |
| **显示驱动模块** | LVGL 屏幕渲染，400×300 单色 | `custom_lcd_display.cc` |
| **设备状态机** | 页面切换、物理按键事件分发 | `device_state_machine.cc` |
| **页面渲染模块** | 各设备页面的 LVGL UI 描述 | `ui_pages.cc/h` |
| **天气协议模块** |心和天气 API 对接 | `weather_api.cc/h` |
| **课程表模块** | 单双周判断、今日/明日课程计算 | `schedule.cc/h` |
| **小智协议模块** | MQTT/WebSocket 与小智服务器通信 | `protocols/mqtt_protocol.cc` |

## 4. 关键设计决策

### 4.1 UI 绘制方式
所有设备 UI 使用 LVGL 原生 API 绘制，不使用 HTML/WebView。HTML 仅用于配网引导的四个网页配置页面。

### 4.2 配网方式
采用 SoftAP（设备建立热点）+ 内置 HTTP Server 的方式，用户手机/电脑直接连接设备热点并访问芯片映射 IP（`192.168.4.1`），无需额外 App。

### 4.3 对话框显示规则
- **首页**：对话条常驻显示，内容为"待命"或最新对话
- **其他页面（音乐/课程表/天气）**：默认不显示对话条，仅在唤醒事件触发时弹出对话浮层，3 秒后自动隐藏

### 4.4 功耗策略
- 屏幕每 60 秒全量刷新一次（LVGL 强制重绘）
- 非活跃页面期间关闭不必要的定时器
- 按键按下时才触发页面切换逻辑

### 4.5 存储结构
所有配置数据（NVS 或 SPIFFS）：

```json
{
  "wifi": { "ssid": "...", "password": "..." },
  "schedule": {
    "start_date": "2025-02-17",
    "end_date": "2025-07-04",
    "single_week": [ ["语文","数学","英语","科学"], ... ],
    "double_week": [ ["语文","数学","英语","信息"], ... ]
  },
  "weather": {
    "key": "...",
    "secret": "...",
    "city": "深圳"
  },
  "device": {
    "setup_complete": true,
    "bind_code": "XZ-2038"
  }
}
```
